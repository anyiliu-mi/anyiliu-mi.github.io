# Recent News Folder

Add news items here as plain `.txt` files. Each file = one news item.

## File naming convention

```
YYYY-MM-DD-short-description.txt
```

Examples:
- `2026-08-07-nsf-grant-awarded.txt`
- `2026-07-20-paper-accepted-sp27.txt`
- `2026-06-15-invited-talk-usenix.txt`

## File content

Write the news text inside the file. Keep it to 1–2 sentences.

Example content:
```
Received NSF award #XXXXXXX to investigate AI safety in autonomous vehicle cybersecurity systems (2026–2029).
```

## How to update the website

After adding or editing files here, say to Claude:

> "update my news"  or  "update news of my website"

Claude will read all `.txt` files, update the website, and push to GitHub automatically.
